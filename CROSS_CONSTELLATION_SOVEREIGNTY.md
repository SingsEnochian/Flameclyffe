This repository follows the active Rowan/Rarity-side invariant in `apps/arcsweep/contracts/CROSS_CONSTELLATION_SOVEREIGNTY_V0.1.md`.

## Repository law

```text
FOREIGN CONTEXT MAY INFORM.
FOREIGN CONTEXT MAY NOT DEFINE.

SOURCE ARCHITECTURE != RECEIVER ARCHITECTURE
SHARED TERM != SHARED SUBSYSTEM
INFERENCE != MAPPING
MAPPING != EQUIVALENCE
INSPIRATION != ADOPTION
INTERSECTION != IDENTITY
CONVERGENCE != MERGER
```

Foreign architecture is read-only context by default. Unknown foreign terms remain unresolved. A foreign idea may become an attributed local proposal, but local architecture changes require an explicit Rowan/Rarity decision. Mappings require explicit approval and preserved provenance.

Shared principles and shared boundary contracts are encouraged when deliberately agreed. They do not merge implementations or ownership.

For runtime behavior, see `apps/arcsweep/src/constellation-sovereignty.js`.
