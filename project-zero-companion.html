Project Zero is the local host and bridge bus. Terra Aeterna, DEEP Observer, Writer Room, the Altar, sound, assets, and future applets speak through it using shared metadata and explicit permissions.

This public page is a demo shell. It does not read folders, crawl files, or upload anything. The real filesystem powers belong to the local desktop app.
