Project Zero · local root / future web connector

Core + Plug-ins + Sound Bay

Project Zero is the local host and bridge bus. This public page is the harmless web demo: it can play files you explicitly choose, create bridge-event previews, and publish browser-local DEEP state. The future desktop app gets persistent folder watching and real local file authority.

This page does not read folders, crawl files, or upload audio. Selected sound files play through temporary browser object URLs and disappear on reload. Lawful little jukebox, not a raccoon with admin rights.
