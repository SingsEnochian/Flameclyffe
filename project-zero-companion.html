Core + Plug-ins + Planning Bays

Project Zero is the local host and bridge bus. Every formerly planned plug-in now has a usable public planning module: Terra Aeterna Root, DEEP Observer Bridge, Writer Room Rail, Asset Watcher, and Sound Bay. The future desktop app gets persistent folder watching and real local file authority.

This public page does not crawl folders, upload files, or pretend to own your machine. It creates local draft events, plays explicitly selected sounds, and shapes the connector contract.
