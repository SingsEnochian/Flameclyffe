# Data Card: Codex Search Synthetic Baseline

## Registry

- Version: 0.1.0
- Owner: Flameclyffe ML Laboratory
- Created: 2026-06-13
- Source systems: synthetic test fixtures only
- Snapshot hash: generated by test fixture content when used
- Privacy class: public

## Purpose

This synthetic fixture set validates the Codex search contracts, chunking behaviour,
privacy gates, and lexical baseline before live Notion, Supabase, or private archive
records are introduced.

## Composition

- Record count: small unit-test documents
- Unit of observation: CanonDocument
- Time span: none
- Modalities: text only
- Labels or targets: expected search hit ordering and visibility filtering
- Missing-value policy: required fields must validate before indexing
- Duplicate policy: deterministic chunk hashes expose repeated content

## Provenance

All records are hand-written synthetic examples inside `ml-lab/tests`. They are not
copied from private notes, Notion records, drafts, medical material, or conversation
archives.

## Consent and permissions

- Collection permission: not applicable, synthetic data only
- Training reuse permission: permitted for test and baseline development
- External sharing permission: permitted as repository test data
- Revocation or deletion path: delete or edit the test fixture
- Licence or contractual limits: project repository rules apply

## Privacy handling

- Included privacy classes: public, internal, private labels for gate testing
- Direct identifiers: none
- Indirect identifiers: none
- Redaction or pseudonymisation: not required
- Storage location: repository tests
- Access controls: repository visibility
- Retention period: until baseline tests are replaced or retired

## Quality review

- Schema validation: Pydantic contracts
- Range and type checks: unit tests
- Leakage review: synthetic-only fixture text
- Sampling or coverage gaps: intentionally minimal
- Label review: deterministic expected results
- Known artefacts: lexical matching is not semantic understanding

## Intended use

Use this data for baseline search tests, privacy-gate tests, chunking tests, and CI.

## Out-of-scope use

Do not use these fixtures to evaluate real retrieval quality, canon coverage, or model
performance on Terra Aeterna material.

## Splits

No train, validation, or test split is required. The fixture set is deterministic and
used only for behavioural tests.

## Limitations

The data is tiny, synthetic, English-only, and deliberately simple. It proves plumbing,
not intelligence.
