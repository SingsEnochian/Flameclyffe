# Model Card: Geometric Manifold Engine v1

## Status

Experimental research engine. Not approved for canon writes, publication decisions,
diagnosis, safety authority, relationship judgement or claims about physical cosmology.

## Intended use

- compare structured geometric bottlenecks against matched neural baselines;
- inspect token-conditioned relational geometry;
- test causal hyperbolic attention;
- visualise deterministic dodecahedral, tesseract and penteract references;
- evaluate projective-quintic constraint proxies;
- train preference models from explicit human-labelled pairs;
- export verified real-valued fixed-profile models after parity testing.

## Components

- fixed reference geometry inspector;
- nonlinear anchor projection;
- differentiable SO(5) penteract rotation;
- Poincaré-ball causal attention;
- projective quintic proxy;
- complex-interference-inspired decoder;
- live-activation geometry loss;
- Bradley-Terry reward loss and DPO helper;
- actual-model ONNX wrapper.

## Prohibited interpretations

The engine does not prove that:

- language occupies physical higher dimensions;
- a dodecahedron is a five-Merkaba object;
- a quintic proxy is a Ricci-flat Calabi-Yau metric;
- model weights reveal an Euler characteristic;
- geometry measures human alignment;
- an interference head solves the Schrödinger equation;
- successful ONNX export establishes TensorRT compatibility.

## Data requirements

Every experiment requires a data card, train/validation/test split, leakage check, source
licence, privacy class, permission state and content snapshot hash. Preference training
requires explicit chosen/rejected examples and permission for training use.

## Evaluation

Adoption requires improvement over:

- a non-neural or ordinary neural baseline;
- a gate-zero ablation;
- random anchors;
- shuffled anchors;
- fixed and dynamic orientation controls.

Report held-out loss, perplexity, latency, memory, parameter count, causal tests, geometry
loss, gate magnitude, token variance and paired-seed generation metrics.

## Deployment

The torch-free reference API may run inside the Living Engine. Trainable modules belong in
an optional local worker. The v1 ONNX profile excludes the projective quintic proxy.
TensorRT and Triton remain unverified until target-runtime build and parity tests pass.

## Authority

Outputs are experimental, reviewable and receipted. The engine has no canon authority.
