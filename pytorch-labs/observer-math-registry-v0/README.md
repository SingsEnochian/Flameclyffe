# Observer Math Registry v0

Nocturne's note: the Observer should not be locked to DEEP Theory. DEEP is one excellent mathematics, but the Observer should also read glyphs, sigils, moon/weather states, gesture traces, sound spectra, lore motifs, and hand-approved material examples.

This lab defines the swappable mathematics layer for STARWELL.

## Core idea

The Observer Engine should ask three questions:

1. **What is the signal source?**
   - DEEP Theory variables
   - Glyph geometry
   - Sigil topology
   - Moon/weather state
   - Gesture or gaze trace
   - Sound spectrum
   - Lore motif vector
   - Human material rating

2. **Which mathematics lens reads it?**
   - Deterministic formulas
   - Symbolic glyph rules
   - Topology features
   - PyTorch MLP or encoder
   - Fluid-dynamics parameter map
   - Hand-authored ritual grammar

3. **Which output head receives it?**
   - Grown-material CSS variables
   - Glyph/sigil rendering weights
   - Liquid-light parameters
   - Tone or haptic recipes
   - Lore continuity checks
   - Caption/accessibility presentation states

## Production boundary

This registry is a lab contract. Production React should receive small exported artifacts first, such as JSON presets, normalized feature maps, or frozen model outputs. Direct live model execution belongs later, only if it remains inspectable, reversible, performant, and consent-safe.
