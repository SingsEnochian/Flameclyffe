# Material Intuition v0

A tiny PyTorch lab for teaching STARWELL how grown materials should respond to observer samples.

This lab is intentionally small. It begins with hand-approved examples and compares learned outputs against deterministic registry outputs.

## Inputs

Each training row can come from any Observer Math Registry source:

- `deep_theory`
- `sigil_topology`
- later: `moon_weather`, `glyph_geometry`, `sound_spectrum`, `lore_motif`, `gesture_trace`

The source adapter converts raw fields into shared observer features.

## Targets

The first target set is grown-material CSS behavior:

- flare hue
- flare alpha
- vein density
- edge softness
- pulse speed
- glass-to-leaf balance

## Rule

The model does not replace the deterministic grammar. It competes with it in the workshop. A learned output only graduates when it is clearer, prettier, and still inspectable.

## First sample modes

- `cold_live`: calm blue-green observational state
- `warm_charge`: brighter gold charged state
- `loch_calm`: quiet deep green state
- `sigil_leaf`: sigil/topology state with more vein and less glass
