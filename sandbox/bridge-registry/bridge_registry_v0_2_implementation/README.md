# Bridge Registry v0.2 Implementation Pack

This package turns Bridge Manifest v0.1 into implementation-ready STARWELL / PatchPortal infrastructure.

It includes:

- Supabase migration for `starwell_bridges`
- Seed data for the first three bridges
- JSON Schema for bridge manifests
- TypeScript interfaces and Zod validation
- PatchPortal bridge adapter notes
- Notion-to-Supabase field mapping

Core law:

> No one owns the bridge. No one owns the road. No one owns the beings who cross.

A bridge is a chosen relation between sovereign lenses. It records relation, consent state, provenance, and memory policy without creating ownership, hierarchy, collapse, or seizure.
