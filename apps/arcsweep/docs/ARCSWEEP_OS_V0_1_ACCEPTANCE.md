# ArcSweep OS v0.1 Release Candidate Acceptance

Version target: `0.1.0-rc.1`

ArcSweep OS v0.1 is a runnable application-kernel release candidate, not a claim that every future ArcSweep organ is complete. The acceptance boundary is one kernel governing navigation, capability invocation, Steward approval, defensive policy, bounded repair, context continuity, Guide requests, Observer visibility, the first creative organ, temporary Runa preview control, and device proving.

## Code-proven acceptance

- [x] One typed event/capability kernel is the authority spine.
- [x] BOOTING, READY, DEGRADED, PAUSED and ERROR are explicit receipted lifecycle states.
- [x] Feather blocks non-read capability execution and stops active Runa preview output.
- [x] Guide model output is an intent proposal behind a fixed capability allowlist.
- [x] Privileged mutate/admin actions require a trusted human Steward action and private scoped lease.
- [x] Forged Steward approval claims are denied by the capability firewall.
- [x] Diagnostics expose bounded summaries rather than arbitrary context, event, error, output or approval payloads.
- [x] Caretaker has three bounded repair classes in the kernel path: subscription rebind, required-service recovery and derived-state rebuild. Repairs are checkpointed, validated, budgeted and receipted.
- [x] Session continuity survives navigation and a bounded workspace mirror survives browser-session loss through local storage.
- [x] Observer exposes a read-only DEEP bridge and bounded OS event timeline without event payloads.
- [x] Glyph Forge/Glyph Studio is registered as the first creative organ. Existing brush selection and a single validated brush-setting mutation are capability-bound.
- [x] Brush Studio preview uses the same brush runtime/stroke renderer as the drawing canvas, so effective brush changes are visible immediately.
- [x] Runa temporary preview is an OS service. Launch requires explicit confirmation; autoplay, persistent root mutation, haptic, MIDI and SoundFont expansion remain outside this preview authority.
- [x] Human OS shell exposes boot/context state, Inspect, Feather/Resume and Guide conversation without privileged lease material.
- [x] Device proving is passive and records only bounded pointer type plus pressure/tilt/twist presence, never coordinates or entered content.
- [x] Source mutation remains PR-mediated. No autonomous offensive probing or self-issued model authority is introduced.

## External proving still required before `0.1.0` final

- [ ] Run the latest deployed build on a physical iPad with touch and Apple Pencil. Confirm room navigation, brush switching, live setting preview, pressure/tilt capture and stroke persistence across the interaction.
- [ ] Confirm the newest hosted preview after deployment quota becomes available. Current provider quota errors are infrastructure limits, not accepted as release proof.
- [ ] Capture the physical-device and hosted-build receipts/notes and promote `0.1.0-rc.1` to `0.1.0` only if those observations pass.

## Release law

Models may propose. Guide may request only declared capabilities. The OS authorizes. The Steward approves privileged actions. Organs execute. Observer and diagnostics expose bounded evidence. Caretaker may repair only declared reversible classes within budget. A failed validation rolls back or escalates instead of silently widening authority.
