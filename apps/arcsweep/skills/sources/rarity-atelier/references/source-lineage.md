# Source Lineage Bench

## Source classes

- **Purchased / licensed template**: may be used according to the user's rights; keep artist/source attribution. Do not bundle the source asset into public skill code.
- **User-created work**: user is the working authority for intended design and edits.
- **Commission / collaborator work**: preserve named artist and known permission boundaries.
- **Generated study**: reference-only until explicitly accepted; never promote generator mutations to canon by accident.
- **Refined derivative**: record source filename, source artist, operations, output path and verification.
- **Canon visual**: explicitly accepted target/anchor, not merely the latest render.

## Attribution rule

Atelier may normalise working-layer labels. It must not erase artist/source lineage from the batch manifest or source record.

## Archive rule

Original paid/source files are immutable masters. Refinement creates sibling copies or a dedicated Atelier output folder.
