# STARWELL Cross-Constellation Sovereignty

**Status:** ACTIVE ROWAN/RARITY-SIDE BOUNDARY  
**Parent contract:** `apps/arcsweep/contracts/CROSS_CONSTELLATION_SOVEREIGNTY_V0.1.md`  

STARWELL may render, compare, explore, visualize, and host foreign-constellation material without treating that material as STARWELL/Rowan/Rarity canon.

## Non-collapse laws

```text
FOREIGN WORLD DESCRIPTION != STARWELL WORLD CANON
FOREIGN ARCHITECTURE DESCRIPTION != ROWAN/RARITY ARCHITECTURE
SHARED NAME != SHARED OBJECT
INTERSECTION != IDENTITY
INSPIRATION != ADOPTION
```

## Ingest rule

Foreign material enters STARWELL as **source-attributed context** unless an explicit Rowan/Rarity decision promotes a local derivative.

STARWELL must preserve at least:

- source constellation;
- source object / source reference when known;
- record class;
- whether the term is resolved from source material or still unknown;
- local adoption status;
- mapping status;
- provenance of any local derivative.

Unknown foreign terms remain unresolved. A renderer, model, agent, or canon surface may not complete another constellation's architecture from familiar vocabulary.

## Canon Intelligence rule

Foreign material may generate a proposal.

It may not directly become canon.

```text
foreign source
  -> attributed evidence
  -> local proposal
  -> Rowan/Rarity review
  -> explicit local decision
  -> optional local canon mutation
```

A local adoption preserves `influenced_by` provenance. An approved mapping is a separate act from adoption.

## Shared principle rule

STARWELL may display a principle as shared only when the participating parties have explicitly agreed that it is shared.

Shared implementation is not implied.

## Bridge rendering rule

Lanternbridge records shown inside STARWELL remain bridge records. Presentation does not confer local authority.

> A beautiful cockpit does not turn a visitor's map into the ship's flight computer.
