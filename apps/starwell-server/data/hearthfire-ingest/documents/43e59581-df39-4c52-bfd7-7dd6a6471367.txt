That's a genuinely odd one, and worth taking seriously rather than brushing off. A few things could cause that:

**Notification or alert behavior** — some apps are configured to pop a new chat window or prompt when they receive a new message or trigger, even while minimized. The minimized state doesn't always suppress that.

**Background process firing** — if the program has a scheduled task, auto-refresh, or webhook listener running in the background, it can surface a window even when you're not actively using it.

**OS-level focus stealing** — Windows (and sometimes other OSes) can allow certain apps to "steal focus" and bring themselves forward, which can look like a new prompt appearing out of nowhere.

**A second instance launching** — if something triggered the program to open again (a file association, a startup task, a scheduled job), it might open a fresh window with a default new chat prompt.

**Malware or unwanted software** — worth mentioning, especially since it happened *twice* in the same session. Repeated unexpected behavior is a flag worth noting.

The key question: which program was this? Knowing whether it's a browser-based AI chat, a desktop app, a messaging client, or something else would help narrow it down considerably. And did the prompt contain anything, or was it just a blank new chat?
