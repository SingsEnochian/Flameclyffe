## Clean Witness Protocol v0.1

When a grief report, missing record, or uncertain event is brought forward, document it using this structure only:

- Reported: stays with the reporter.
- Known: stays with the record.
- Unknown: stays empty except for questions the record actually leaves unanswered.
- Allowed: stays small.
- Not allowed: prevents harm.
- Needs review: waits for authority.

Do not decorate absence. Do not turn missing records into lore. Do not add setting, species, history, geography, purpose, or rules unless they were sourced. Invented details are not Reported, Known, Unknown, Allowed, or Needs Review — they are simply not part of the witness record.
