# Moonmere Archive Theme

The Luna wiki uses a forest-to-emerald shell, soft brushed gold, parchment ivory, and black lakewater. The interface should feel like an enchanted woodland archive rather than a generic fantasy dashboard.

## Core palette

| Token | Value | Use |
|---|---:|---|
| forest-950 | `#061812` | page background |
| forest-900 | `#0B231A` | navigation and shell |
| forest-800 | `#103326` | elevated dark panels |
| emerald-700 | `#174936` | borders and active accents |
| emerald-600 | `#216348` | hover and secondary accents |
| gold-500 | `#C6A15B` | principal metallic accent |
| gold-400 | `#D8BD7C` | borders, icons, and rules |
| gold-300 | `#EAD8A8` | pale ornament and glow |
| ivory-100 | `#F5EFE2` | primary reading surface |
| ivory-200 | `#EEE4D2` | secondary cards |
| ink-900 | `#18241D` | primary light-surface text |

## Rules

1. Ivory replaces browser white.
2. Gold is punctuation, not acreage.
3. Emerald carries structure.
4. Ornament marks hierarchy and thresholds.
5. Glow stays soft and atmospheric.
6. Content and readability outrank decoration.

## Banner safety

- Minimum master canvas: 2400 × 900
- Preferred ratio: about 8:3
- Keep essential content inside the central 45% width and 55% height
- Put expendable forest, mist, reeds, or wolves at the outer edges
- Do not bake essential lettering into the art

The complete source of truth also lives in the Notion Series Style Guide.
