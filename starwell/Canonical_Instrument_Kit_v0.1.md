# STARWELL Canonical Instrument Braid v1.8

**Status:** ACTIVE  
**Governing mathematics:** `docs/HEARTHGATE_BRAIDED_SPINE_V1.8.md`

The Canonical Instrument Braid defines the shared behaviour, visual language, accessibility controls, receipts, and interaction grammar for STARWELL instruments.

Every instrument is a working organ of the same braid. Data, mathematics, rendering, interaction, consciousness, relationship, world state, sound, movement, and lineage remain connected through explicit contracts.

## Purpose

STARWELL instruments read, transform, express, and receipt living state.

They translate PREMAQC, relational state, world state, temporal state, observation coupling, and lineage into geometry, motion, sound, haptics, language, and reproducible receipts.

Every response serves at least one active function:

1. Reveal current state.
2. Reveal relationship among states.
3. Preserve lineage.
4. Expose the mathematics.
5. Carry world-native expression.
6. Support interaction and embodiment.
7. Produce a replayable receipt.

Visual delight is an expressive layer of the instrument. It remains connected to the underlying state and lineage.
