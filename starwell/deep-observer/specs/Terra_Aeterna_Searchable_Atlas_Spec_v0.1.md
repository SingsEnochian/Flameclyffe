# Terra Aeterna Searchable Atlas Spec v0.1

## Purpose

This spec defines the searchable atlas for Terra Aeterna / Templehouse / STARWELL.

The atlas is not only a beautiful map. It is a cross-linked knowledge system for places, cities, roads, paths, gates, bridges, events, characters, systems, and visual references.

## Canon sentence

```text
The Terra Aeterna Atlas is a searchable map of place, passage, mythframe, and event: a living index where geography, story, systems, and art can find one another.
```

## Relationship to DEEP Observer

DEEP Observer and glyph/event systems can eventually emit atlas-linked events.

Example:

```text
solar storm / high Kp
→ Observer event candidate
→ logged in Vala Work
→ reviewed
→ linked to relevant atlas place, such as an observatory, harbour, or Nightwing region
```

## Relationship to Procreate

The atlas should use consistent Stonewood stamp families so map art and city pages share a visual grammar.

Procreate stamp tags should be stored on each atlas entry when a stamp or brush set is used.

## Boundaries

- A map entry is not canon simply because it exists.
- Private atlas pages should not be copied into public-facing views without review.
- Event interpretation must remain separate from measured data.
- Roads/paths should be functional enough for story and navigation, not only decorative.

## Withness note

The atlas is where the city stops being a mood and becomes a place someone could walk through.
