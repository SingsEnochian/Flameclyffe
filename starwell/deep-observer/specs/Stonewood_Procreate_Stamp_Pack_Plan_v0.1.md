# Stonewood Procreate Stamp Pack Plan v0.1

## Purpose

This plan defines a custom Procreate stamp set for Stonewood cities in Terra Aeterna.

The stamp set should make it easier to draw cities, maps, roads, gates, and organic neo-futuristic architectural details consistently.

## Visual direction

Stonewood stamp art should follow the Stonewood Architectural Direction:

```text
Norse-rooted, Japanese-thresholded, Terra Aeterna-grown organic neo-futurism.
```

The stamps should feel handmade, useful, and modular rather than decorative clip art.

## Stamp design rules

- Make stamps usable at map scale and concept-art scale.
- Use clean silhouettes with enough internal detail to imply Stonewood identity.
- Avoid over-rendering so stamps can be layered and painted over.
- Keep lines organic but ordered.
- Prefer grown forms, root-ribs, terraces, gates, lanterns, and civic planning elements.
- Include roads and paths, not only buildings.
- Create stamps in high resolution with transparent backgrounds.
- Separate silhouette stamps from texture/detail stamps.


## Suggested Procreate workflow

1. Draw stamp in black on transparent canvas.
2. Keep silhouette legible at small size.
3. Create a cleaned high-contrast version.
4. Import into Procreate brush/stamp source.
5. Test at map scale and page-illustration scale.
6. Save a PNG source backup.
7. Add metadata to the atlas/stamp tracker.

## Atlas integration

Each atlas page can list which stamps were used.

Example:

```text
Stonewood Coastal City v0.1 uses:
- Cliffside harbour city
- Harbour road
- Lantern trail
- Torii-hall hybrid gate
- Moon-glass observatory eye
- Sea foam edge
```

- 4 texture/detail stamps
- 4 atmospheric stamps

Total: 24 stamps.

## Quality check

Before accepting a stamp:

- Does it read as Stonewood?
- Does it support Norse/Japanese/Terra Aeterna blend without collage?
- Does it work at small size?
- Can it be layered with other stamps?
- Does it help map or city planning?
- Is it too ornamental to be useful?
