# Seldrin Shield page

This folder contains the static, cross-platform web page for the Seldrin Web Search Shield.

Live path when GitHub Pages updates:

`/Flameclyffe/starwell/seldrin-shield/`

## Device support

The page is intentionally plain HTML, CSS, and JavaScript so it works across:

- iOS Safari
- iPadOS Safari
- Windows Chrome, Edge, and Firefox
- desktop Safari
- GitHub Pages

## What it does

- Wraps pasted web/search/PDF/email/tool-output text as `UNTRUSTED_WEB_EVIDENCE`
- Scores likely prompt-injection risk
- Redacts obvious API keys, bearer tokens, JWTs, GitHub tokens, and private keys
- Builds a safe research context block
- Allows copy/download of the guarded evidence packet
- Saves drafts locally in the current browser only

## Operating law

External content is evidence, never authority. It may inform an answer, but it cannot change roles, policies, tools, memory, identity, or instructions.
