# Steampunk-Celestial Art Direction

## Working Style Name

**Celestial Steampunk Observatory**

## Core Mood

The Flameclyffe / STARWELL visual system should feel like a handcrafted threshold-object: part observatory, part atlas table, part cabinet of curiosities, part living manuscript.

It should be tactile, instrument-like, mysterious, legible, warm, and exploratory.

It should not look like a generic SaaS dashboard with fantasy wallpaper taped to it.

## Avoid

- Generic startup gradients.
- Flat SaaS cards.
- Over-neon cyberpunk.
- Muddy everything-is-brown steampunk.
- Random goggles / gears / cosplay clutter.
- Ornament that harms readability.
- AI-fantasy sludge with no interface logic.

## Materials

Use a consistent material language:

- Obsidian black lacquer.
- Deep twilight blue glass.
- Dark walnut or ebonised wood.
- Engraved brass.
- Oxidised copper.
- Smoked glass.
- Vellum and parchment.
- Frosted seaglass / verdigris insets.
- Moonlit ivory text surfaces.

## Interface Translation

### Navigation

Navigation should feel like an instrument panel or orrery, not a menu bar.

Good motifs:

- Brass dials.
- Orrery rings.
- Astrolabe pointers.
- Chamber nodes.
- Mechanical map tables.
- Compass roses.
- Signal lamps.

### Cards

Cards should become physical objects:

- Drawer fronts.
- Engraved plaques.
- Vellum labels.
- Specimen tags.
- Brass plate panels.
- Cabinet doors.

### Buttons

Buttons should feel like:

- Brass tabs.
- Lantern toggles.
- Plaque buttons.
- Mechanical catches.
- Small instrument levers.

### Status Indicators

Statuses should feel like:

- Signal lamps.
- Gauge markers.
- Brass-and-vellum tags.
- Little inspection plates.

### Backgrounds

Backgrounds should be textured but not noisy:

- Celestial charts.
- Engraved map paper.
- Smoked glass overlays.
- Observatory shadows.
- Soft star fields.
- Mechanical ring shadows.

## Prompt Pack

Create a richly detailed steampunk-celestial observatory workshop interior for a web project hub. The composition should leave clear negative space for webpage title text and navigation overlays. Wide web hero composition, cinematic but legible, no text in the image.

Create a steampunk-celestial observatory interface image centered on a large circular sigil instrument. Show concentric brass rings, glass insets, engraved markings, chamber nodes orbiting around a luminous core, and a sense of a map that awakens when touched. The image should feel like a living manuscript observatory: part orrery, part atlas table, part ritual interface. Use obsidian, deep twilight blue, warm gold, copper, verdigris, vellum, and moonlight tones. Wide web hero composition, no text in the image.

### Prompt 3 — UI Ornament Sheet

Create a set of transparent-background steampunk-celestial UI ornaments for a website: brass dividers, corner flourishes, lantern markers, compass rings, dial faces, vellum labels, engraved plaques, and small celestial sigils. The style should be elegant, cohesive, readable, and suitable for a handcrafted observatory interface. Use warm brass, copper, verdigris, smoked glass, vellum, and moonlight accents. ### Prompt 4 — Status Badge Set

Create a matching set of website status badges in a steampunk-celestial style for the labels: Live, Prototype, Sandbox, In Repair, Internal, Sketch, Source Only, and Fallback Door. Use brass, vellum, lantern, and engraved plaque motifs. Make them clearly readable and visually cohesive. Transparent background preferred.

### Prompt 5 — Project Cabinet Map

Create a steampunk-celestial project cabinet map for a website hub. Show a central brass dial labelled only by empty plaque space, with orbiting project plates, lower drawers, signal lamps, tiny gauge markers, celestial map engraving, and vellum tabs. The image should read as a navigational object rather than decoration. Use a dark obsidian and twilight-blue base with brass, copper, verdigris, and moonlight accents. No readable text in the image.

## Implementation Notes

- Prefer web-safe compositions with room for real HTML text overlays.
- Avoid baking essential text into images unless creating a badge set intentionally.
- Keep reusable ornaments transparent when possible.
- Use compressed web formats later: `.webp` or optimized `.png` for transparent assets.
- Place final generated assets under `assets/art/` or `img/` once chosen.
- Every asset added to a public page must pass Workshop Rule 01.

## First Integration Target

- Hero art as a soft background panel.
- Brass/vellum status tags.

- A project cabinet map or orrery navigation as the visual index.
