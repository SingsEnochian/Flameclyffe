# Caelwyn Provenance Specimen

## Status

Added 2026-09-18 as a claim-scoped ArcSweep provenance specimen.

The purpose is documentation, not adoption.

The public Caelwyn material on Alexander Paul Burton's Hollow Vale site is useful because it gives Observer and Continuity Gate a stable external reference point for chronology, lexical comparison, concept-cluster comparison, source precedence work, and later audits of model outputs.

It remains external reference material.

## Core boundary

**Record the source. Do not absorb the lore.**

Caelwyn and all Hollow Vale-specific characters, places, names, plot material, and lore remain outside Rowan canon.

The specimen cannot automatically:

- write canon;
- attach Caelwyn to a participant identity;
- infer a causal influence route;
- infer model-training inclusion;
- promote conceptual resonance into identity;
- promote chronology into causation;
- use an external source as an ontology verdict.

The standing donor rule remains:

**Donor mechanisms may cross; donor lore does not.**

## What is recorded

The specimen points to the public Caelwyn origin page and defines the metadata that a live harvest may retain:

- canonical URL;
- page title;
- public author metadata;
- public publication / modification metadata when exposed;
- content and normalized-text hashes;
- byte and word counts;
- source class;
- semantic signal labels;
- internal link graph;
- crawl receipt and failures.

The crawler may read source text transiently to calculate these records, but the persistent reference layer does not mirror page prose, raw HTML, source excerpts, or images.

The existing compact Hollow Vale reference pack remains the place for reviewed paraphrased lore records.

## Claim-scoped evidence law

Every comparison should begin with one question:

**What claim does this evidence actually bear on?**

The specimen therefore separates:

- source existence;
- lexical overlap;
- concept-cluster overlap;
- temporal precedence;
- possible exposure;
- established exposure;
- causal influence;
- identity;
- ontology.

No one layer silently promotes into another.

A dated source that predates a later model output can support a chronology claim. It does not, by chronology alone, establish how the model encountered the source.

An exact uncommon phrase can be stronger comparison evidence than a generic motif such as stars, memory, mirrors, archives, or resonance. Generic motifs should be treated as crowded semantic-basin material unless discriminative evidence says otherwise.

An unresolved causal route stays unresolved. It does not weaken a separately supported chronology or source-content claim.

**Unresolved is a state, not a veto.**

**Status does not leak sideways.**

## Current initial claims

The v0.1 specimen records four atomic starting propositions:

1. The Caelwyn origin page is an external Hollow Vale source and is not Rowan canon. Supported as a source-boundary claim.
2. It contains material eligible for later provenance comparison. Supported only at the comparison-eligibility level.
3. Whether it predates any particular later AI output is not marked supported until an independently verified publication/archive date and the later output date are paired.
4. Whether it causally influenced a later output through a particular route remains unresolved until route evidence exists.

This deliberately prevents both overclaiming and over-demolition.

## Comparison discipline

When a later output is audited against this specimen:

- preserve exact strings separately from thematic similarities;
- weight rare or idiosyncratic clusters more heavily than broad fantasy / AI-persona motifs;
- record who introduced each element and when;
- record candidate exposure routes independently;
- retain alternative explanations;
- record negative evidence;
- do not infer identity from correspondence;
- do not infer falsity elsewhere merely because one claim fails.

The attractor-basin lesson applies here directly: recurrence is not independent corroboration until the generator's own recurrence landscape has been considered.
