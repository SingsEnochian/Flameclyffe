# Mythience Reality Loop v0.1

Mythience is the discipline for investigating meaning-rich, speculative, synthetic, anomalous, and ordinary empirical material without flattening distinctions between evidence classes.

This slice does **not** claim physical multiverse traversal. It establishes the executable architecture needed to compare addressable realities, preserve traveller invariants, request bounded action, and close the result back into observation.

## Six planes

1. **Sensing** — Observer / DEEP / instruments. Owns observations, not conclusions.
2. **Cognition** — ArcSweep / Cognitive Field / Laya / Wonder. Owns interpretation and judgement, not authority.
3. **Possibility** — PREMAQC / trajectories. Owns candidate futures, not execution.
4. **Reality** — Universal Codex / RealityDescriptor / CorrespondenceMap. Owns topology and provenance, not canon promotion by inference.
5. **Capability** — Hearthweave capability contracts. Owns permission and route decisions.
6. **Execution** — Project Zero / sandbox / tools. Owns bounded effects and receipts.

Three concerns cross every plane: **continuity, receipts, provenance**.

## Shared event grammar

`hearthweave.mythience-event/v0.1` carries a common envelope across plane boundaries:

- id and event type
- source plane and runtime
- subject
- timestamp
- before / after state
- evidence references
- provenance
- bounded uncertainty
- authority actually used
- continuity references
- receipt ancestry
- evidence class
- bounded payload

Evidence classes deliberately include established science, active research, speculative theory, fringe inspiration, implementation tasks, evidence-backed findings, and synthetic tests. A change of shelf requires explicit evidence; repetition alone does not promote a claim.

## RealityDescriptor

`arcsweep.reality-descriptor/v0.1` records:

- identity and label
- provenance class
- observational basis
- state dimensions
- invariants
- governing rules
- measurable constants
- causal constraints
- coordinate and observer models
- uncertainty
- branch parent and divergence events
- correspondence targets

A descriptor is a representation of a reality or synthetic world, not proof that the represented world physically exists.

## CorrespondenceMap

`arcsweep.correspondence-map/v0.1` compares two descriptors without merging them. Matching and differing dimensions, invariants, governing rules, constants, and causal constraints remain inspectable.

Traveller-invariant conflicts are elevated separately. If invariants conflict, `transitionCandidate=false`; the runtime holds rather than executing.

## First executable loop

`runMythienceRealityCycle()` stacks on ArcSweep Ignition:

```text
observation
  -> sensing event
  -> trajectory excitation
  -> possibility evaluation
  -> reality correspondence
  -> cognition with correspondence context
  -> capability request
  -> bounded negotiation
  -> sandbox execution
  -> validated receipt
  -> execution event
  -> feedback observation
```

The first intended substrate is synthetic reality comparison. This lets ArcSweep test navigation logic without treating simulation success as evidence of physical universe traversal.

## Invariants

- cognition cannot create authority
- possibility cannot execute
- correspondence is not equivalence
- similarity is not shared canon
- a RealityDescriptor is not an existence claim
- traveller invariants must not be silently rewritten
- execution requires an existing capability route
- applied execution requires evidence-bearing receipt validation
- synthetic success remains synthetic evidence
- unknown remains unknown
