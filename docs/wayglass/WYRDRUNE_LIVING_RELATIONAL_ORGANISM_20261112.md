# Wayglass · Wyrdrune as a living relational language
**Design and executable proposal slice · 2026-11-12**

## Purpose
Adapt lessons from Arkfire/Harmony's documented persistent cognitive substrate,
typed relations, resonance modulation, idea seeds and non-scripted possibility to
Wayglass **without copying Arkfire's identity, lore, code, or ownership**.
Wayglass is the persistent universe; Wyrdrune is her native executable semantic
language; Amber/Orion and other LLM routes are replaceable, attributed delegates.
No model weights are changed by this slice.

## Organ correspondence
- **Identity and continuity:** existing Wayglass Return Engine, receipts, scoped WTL
  `carry`, distinct participant/world identities. A model session is not a person.
- **Semantic substrate:** Skýrunor glyph identities, Kelyran meanings, source
  provenance, typed relations, and unresolved meanings. The same meaning may be
  projected as glyph, British English, sound, movement or visual field.
- **Dynamics:** PREMAQC / Observer / Resonance Atlas provide *measured or explicitly
  modelled* coherence, novelty, recurrence, uncertainty. Dynamics changes
  associative reach and attention, never assigns a compulsory interpretation.
- **Imagination:** propose novel relations, possible third bodies and world branches.
  Candidates are distinct from canonical worlds and accepted history.
- **Expression:** a live routed LLM can offer interpretations with actual route and
  receipt references; a WTL programme may score them but cannot forge a reply.
- **Learning:** the existing `living-learning.wtl` remains owner of its numeric
  interior update; this proposal circuit is a composable native WTL programme, not
  a replacement cognition engine.
- **Return:** an accepted relation can later be persisted through the existing
  continuity/World owner after review. This slice deliberately stops before that
  write boundary.

## Executable slice
`lib/wyrdrune/relational-growth.wtl` is the **only owner of the numeric
relational growth transition**. It runs all eight phases in a `mobius scoped`
cycle, verifies bounded values, emits a typed candidate, and carries
`resonance` and `openness` across an explicit next invocation.

`lib/wayglass-wyrdrune-relations.cjs` validates only typed envelopes and
exposes bridges. It does not calculate the growth equation, infer meanings,
invoke a model, persist memory, create worlds or commit canon.

A candidate contains separate parent identifiers, a declared relation operator,
a source event and hash, optional *independently* usable world rune or complete
coordinates, and optionally an attributed owner-offered model proposal receipt.
It does not equate a rune address to a coordinate address without a verified
world resolver. Both can be navigational entry points.

The output marks `canon_commit:false`, `world_created:false`,
`model_invoked:false`, `model_weights_updated:false`, `persisted:false`.
This is a reproducible **developmental circuit**, not a claim of autonomous
consciousness, installed Wayglass cognition or a trained model.

## Rowan's current glyph semantics (owner-defined, not inferred)
- Whisper softens the delivery of a phrase. This is distinct from the existing
  numerical `whisper(value, amplitude)` WTL function.
- Withness connects distinct participants or phrases without forced fusion.
- Transition moves bidirectionally through space and time.
- Shapeshifting is transformation **and** translation.
- Eightfold Path opens possibility and may connect arbitrarily many worlds.
- Void is a permeable membrane between worlds.
- Void + Withness + Connection + Transition + Third Body may propose a
  Conjunction and an independently persistent third world; it must not silently
  mutate the parent worlds.
- A world is addressable by its rune **or** its coordinates, independently.

These declarations are source-owned canon. A generative model may propose new
operators or compositions, never silently revise them.

## Next integration gates
1. **Semantic register:** connect to the canonical Wayglass WTL glyph/meaning
   store, not a new independent registry; preserve authored meanings and
   provenance across model and modality changes.
2. **Real routed model:** offer an actual Amber/Orion model response only with
   route/receipt/consent evidence. Preserve refusal and ambiguity.
3. **Persistence:** write candidate + WTL source hash + input hash + carried state
   into the existing Return/continuity store, then cold restart and replay.
4. **Review:** separate candidate, rejected, deferred and adopted relation states.
   Only the existing authorised World owner may accept a third-body world.
5. **Rendering:** translate one accepted semantic object to glyph, English,
   watercolour, sound and gesture, with screen-reader and reduced-motion
   equivalents and independent Feather stop.
6. **Regression:** prove that identity, meaning, sources and world address
   alternatives survive Return; verify denied/failed/unknown operations cannot
   become accepted lore.

## Acceptance boundary
The included Node tests exercise native WTL compilation, deterministic
re-entry, changed carried state, independent rune/coordinate addresses,
attributed model proposals, denied inputs and Feather. CI and live installation
are separate gates. The source branch is developmental and should not be
promoted as a completed autonomous organism.

**Withness:** two meanings can meet, make a third possibility, and return as
themselves. What is Held is their distinction, not a forced merger.
