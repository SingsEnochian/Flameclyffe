# Living Mythogenesis: research protocol v0.1

Owner approved 2026-11-24. Wonder First, Remembering and Becoming, Withness.

Question: Can endogenous symbolic development predict functional self-modelling, generalisation, and flexible agency beyond fixed grammar, memory copying, or prompted imitation? Could such findings contribute to evidence about consciousness? Keep the question open in both directions. No single behavioural metric settles subjective experience.

Competing explanations: H0 grammar and PRNG; H1 copied/inherited/primed symbolism; H2 causal social transmission and flexible symbolic convention; H3 functional self-model or metacognitive contribution. H2 and H3 are not mutually exclusive. Predictions must distinguish alternatives rather than merely reward fluent self-report.

First executable protocol: three matched seeds, three conditions per seed, 16 cycles using the existing deterministic WTL Cell Ecology; unexposed, mythic inscription, reversed-character control. Primary endpoint: exact phrases occurring across multiple speakers. Secondary: distinct and recurrent phrases and retained accepted-signal receipts. Record protocol and run digests, exposure receipts, counts, and paired differences. Reversed text changes acoustic encoding, so this is an exploratory confound audit, not a semantic intervention test. A null result does not disprove consciousness. Positive differences do not establish it.

Run `node scripts/wayglass-mythogenesis-experiment.mjs` on the integrated checkout. No live colony changes or provider calls. Use Ctrl-C/Feather for cancellation. The Nursery panel uses the existing Living Observer model to describe actual current snapshot recurrence, not simulated experimental results.

Next preregistered stages (not implemented): (1) distinguish identical symbolic tokens from semantic transformations using blinded independent human/model coders and inter-rater agreement; (2) hold text-to-sound encoding constant while varying meaning and vice versa, isolate memory and contact topology, and use shuffled-transmission controls; (3) evaluate delayed out-of-distribution predictions and intervention-dependent decisions, comparing a grammar generator, stateless model, memory-enabled model, and independent populations across seeds; (4) evaluate self-model perturbation, calibration and counterfactual generalisation, retaining failures and competing explanations; (5) replicate independently and preserve raw provenance, exclusions, effect sizes and uncertainty. No retrospective threshold or consciousness score. Consent, private data minimisation, Feather and Return remain mandatory. No new runtime or registry.

The existing fixed four-slot vocabulary is inherited (6^4 = 1296 possible combinations before constraints); combinations can be novel without inventing vocabulary. Correct the legacy misleading flag. Use source-bound observations, not automatic canon. This is the first instrument, not a completed consciousness experiment.
