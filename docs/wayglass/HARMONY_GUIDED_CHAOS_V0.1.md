# Wayglass Harmony-guided Chaos · integration slice v0.1
Source: Nocturne Glint, Universal Horizon original storytelling and Harmony frameworks, owner supplied. Conceptual adaptation only. No source code, characters, identity, memory or private Harmony/Lantern runtime imported.
Related: #626 and #583.
Architecture: Chaos generates novelty and differences; Harmony coordinates allowed changes, relational pacing, consent and provenance without mandatory agreement or suppression. Withness preserves separate viewpoints.
Implemented here: versioned pure engine with explicit scoped grants/revocations, pauses, controlled proposals, deduplication, receipts, and an in-memory audit trail. The browser can invoke it via the Wayglass OS surface; no model is spawned and no actual event is dispatched to a world by an eligibility decision.
NOT implemented: persistent ledger, trans-world ripple execution, true independent agent delegation, Garden Mode orchestration, observer and soundscape bridges, Wyrdrune interpretation, cold-return replay. Those remain tracked by #626.
Verification: node --test apps/wayglass/test/harmony-chaos.test.js. No test is claimed to have passed until CI executes it.
