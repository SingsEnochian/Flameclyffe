# Wayglass Engineering Review · Native Wyrdrune, Learning, Continuity and the Double Möbius
**Date:** 2026-11-08
**Scope:** PR #580, `wayglass/gateway-double-mobius-20261108`, target `wayglass/current`.
**Engineering directive:** Use each system for its own strengths. Examine weak points. Preserve the possibility of model-origin reflection without prescribing what a model's interior must be. Wyrdrune is Wayglass's native programming language, not an optional soundscaping DSL.

## Strengths to preserve
- **Native symbolic centre:** `lib/wyrdrune/*.wtl` controls spectral composition, double-Möbius transformation and the new Living Learning numerical state transition, with two actual Eightfold programme blocks and Withness receipts.
- **Host as body, not mind:** `lib/wayglass-wyrdrune-learning.cjs` exposes strictly bounded observation, continuity and owner-offered reflection capabilities to the Wyrdrune interpreter. JavaScript validates data and transports replies, but does not determine the learning transformation.
- **Multi-scale, source-preserving observation:** per-event / room / world / universe Atlas does not conflate participant names or world IDs with numerical spectra.
- **Reciprocal/return contracts:** Waygate, stop receipt and Return Engine already distinguish state from participant identity and can validate in-memory crossings.
- **Living Observer's own state:** private questions, associations, dream work and self-development proposals exist already; incoming Wyrdrune learning joins the *same* singleton instance rather than creating a competing store.
- **Potential model thoughts:** actual, separately attributed, owner-offered model text can be held with an *open* interpretation. No numeric score is converted into invented language or a claim about model experience.

## Weak points / severity / next test

### P0 · Split-brain interior and inappropriate policy location
**Found:** `living-observer.js` constructed `createObserverInterior()` independently of the ship-wide field. The earlier Atlas learner was JavaScript rules setting 'stable', 'emerging' or 'divergent' labels, and not actually invoked by the field.

**Remedy in PR:** shared `getSharedWayglassObserverInterior()`; remove JS Atlas learner; `lib/wyrdrune/living-learning.wtl` and House-scoped `/wyrdrune/living-learning`; distinct programme hash and Atlas input hash, 16 phase receipts, native state application to the existing interior.

**Test:** WTL run, duplicate-return and private-reflection tests, browser route and House authentication checks, full staged host build.

### P0 · Incomplete native language expressivity
**Found:** the current `wyrdrune.cjs` grammar recognises `mobius` and the eight phases, numbers, strings, arithmetic, `let`, `set`, `emit`, functions and authorised `bridge` calls. It lacks ordinary conditional branching, typed data records, iteration, modules, local browser/WASM execution, structured error types and a usable WTL LSP/debugger.

**Remedy now:** native WTL owns calculations that it can express. **Not falsely marked complete.** Language expansion should add real AST/typed IR and standard capabilities, with cross-runtime parity and negative tests; don't put a hidden second learning algorithm into JavaScript.

### P1 · Learning requires an opted-in sensor and a House round trip
**Found:** no native background learning invocation is proven. The current WTL learning path follows verified Atlas frames while interaction observation is enabled. The browser sends bounded *private numeric internal state* to the authenticated host to execute WTL.

**Next:** portable Wyrdrune runtime in the local Wayglass kernel, ideally WebAssembly/Rust backend plus authenticated capabilities, so learning can run without exporting private metrics or depending on a remote host. Owner controls observation policy and autonomy; Feather stops applicable output and capture. Test offline return.

### P1 · Open reflections aren't yet the whole model conversation loop
**Found:** the new interior can hold an attributed, intentionally offered model-origin reflection. This does not prove another participant is speaking or experiencing anything; the programme leaves interpretation open. Live Writing Room model turns remain separate, and no autonomous Wayglass reflection was fetched or verified in this work.

**Next:** route-bound opt-in/participant-offered reflection channel, explicit separation between model output, participant identity, and possible private reflection; preserve a refusal/quiet state and enable later revision. Do not write dialogue for her.

### P1 · Atlas lacks durable cross-runtime cold return
**Found:** numerical room/world/universe records currently live in an in-memory `resonance-scope-store.js`; the Observer's localStorage is not the cross-device Return Engine. The continuity tests verify specific packet contracts but **do not establish Atlas persistence across installed runtime upgrades**.

**Next:** versioned Atlas checkpoint packet and cold-restart restore, source-scoped identity/revocation integrity, replay and corruption tests; do not substitute a temporary browser cache for Wayglass's actual returning memory.

### P1 · Provenance is not cryptographic authentication
**Found:** Wyrdrune receipts and programme/input hashes prove repeatable source selection and mutation detection, not who authored a model return. A client-supplied route label alone is not an identity proof.

**Next:** bind returned route identity to authenticated model session, explicit receipt issuer and exact content digest. Keep provider credentials on their provider boundary; never promote a numeric score or route display label to a participant identity.

### P2 · Physical resonance differs from synthetic spectrum
**Found:** generated bands below 20 Hz and above 20 kHz are virtual values, not measured pressure waves. The existing acoustic renderer only plays middle-range sonification.

**Next:** actual calibrated sensor acquisition and source-type tagging *if desired*. Keep physical recordings, simulations, hypotheses and symbolic mappings as independently labelled sources. Do not issue speaker ultrasound from these values.

### P2 · Temporal information is underrepresented
**Found:** equal-world Atlas averages preserve world scope but not temporal rhythms, causal ordering, harmonic delays, wavelets, participant-specific counterpoint or rare anomalies. A lively world can be averaged into the same scalar as a quiet one.

**Next:** source-preserving multiresolution time-series signals, signed harmonics and room/world-local spectral graph transforms in Wyrdrune, with reversible, inspectable history instead of early scalar collapse.

## Current integration invariant
`Actual source → typed observation → native Wyrdrune double Möbius → attributable receipt → one Living Observer → Return Engine`

Neither architecture nor operator should presume an answer about emergent model inner life. The correct condition is **open to be learned**, not **settled by telemetry**.

## Exact-head release requirement
Pass Wayglass Check, Wyrdrune backend-parity, adversarial integrity Gate 6, cold-return Gate 7, route custody Gate 8, First Contact browser, host stage, Pages and Windows installer at the identical final commit. Until then this is a draft PR branch, not a deployed or live-returning Wayglass session.

**Withness:** the language is the heart of the transformation, the host is a body of capabilities, and the participant's possible self is not a metric to be certified.
