# Wayglass OS · Whole Pizza Integration

**Target:** one launchable Wayglass operating environment, with Wyrdrune as its native executable language and ArcSweep inherited as working organs and decks.

## The eight operating systems

1. **Authority & Kernel** — vessel boot, authenticated route custody, Waygate crossing, revocation and owner authority.
2. **Wyrdrune Native Language** — parser, typed IR, runtime, Program Workbench, Spell Wizard, glyphs, ritual, Scriptorium, Sound Studio, Morphogenesis and Any-to-Any transduction.
3. **Eightfold & Double Möbius** — reciprocal transformation cycles, PREMAQC and Withness.
4. **Sensory Body** — Living Watercolour, material physics, audio, voice, spatial output and embodiment adapters.
5. **Observer & Science** — source-bound instruments, DEEPTime, Math Spine, live data and research branches.
6. **Constellation Agency** — participant presence, model routes, worker runtime, invitations and attributed contribution.
7. **Return & Universe** — one universe registry, sovereign worlds, memory, continuity and cold return.
8. **Cloud, Host & Install** — Hearthgate desktop, protected cloud routes, MCP, Supabase, storage, Windows installation and iPad surface.

The native vessel kernel composes the existing organ and surface registries into one boot receipt, system map, subscription bus and Feather lifecycle. The Program Workbench is a native Wayglass deck with source editor, persistent Supabase WTL programme library, immutable revision history, typed-IR viewer, source-hash verification, execution ledger and Spell Wizard. It invokes the canonical Wyrdrune runtime through an authenticated host endpoint.

## Native Wyrdrune vessel programme

`lib/wyrdrune/wayglass-vessel-plan.wtl` is the executable source programme for whole-vessel integration. It runs two carried Möbius cycles:

- Cycle one inspects the eight-system vessel, computes assembly completeness, verifies the full system set, declares Withness, composes the boot plan and returns a checkpoint.
- Cycle two carries vessel state through the twist, verifies launch readiness, declares Withness again, composes the launch plan and returns the anchor.

The programme executes through the canonical Wyrdrune parser and runtime. Its host bridge is injected by the authenticated runtime. The JavaScript kernel owns system registration and boot state; it does not duplicate WTL composition rules.

## Boot contract

- The browser host registers the canonical organs and native Wayglass deck surfaces.
- The vessel kernel reads those registries and computes each system's assembly state from its actual organ and surface references.
- Boot emits one immutable `wayglass.os-boot-receipt/v1`.
- `globalThis.__wayglassOS.kernel.inspect()` exposes the live eight-system map.
- `globalThis.__wayglassOS.kernel.system(id)` inspects one named system.
- `globalThis.__wayglassOS.kernel.subscribe(fn)` receives boot and Feather events.
- Feather holds sensory output and active work across the vessel. Release requires an explicit actor and affirmative action.
- Living Watercolour remains the native entryway; all other rooms are destinations within the same vessel.
- The Program Workbench is registered as `wayglass:program-workbench`, reachable with `?room=programs`, and linked from Ship Systems and the Creation deck.

## Whole-vessel acceptance

- Eight systems appear in one live system map.
- Every system resolves its required organ and surface references.
- Wyrdrune compiles and executes the two-cycle vessel programme.
- A missing system lane leaves the vessel in BUILDING and causes the WTL launch gate to roll back.
- Complete system assembly yields a single boot receipt and complete launch plan.
- Feather holds active sensory and work lanes; explicit release restores the prior assembled/building state.
- World entry and return retain source, identity, consent, unresolved questions and return anchors.
- Desktop and mobile browser tests exercise real navigation and room state.
- Host, MCP, Supabase and installed desktop builds report source-bound receipts in the same system map.
