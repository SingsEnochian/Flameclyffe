## Build generations

1. **Discover:** pin main, relevant open PRs and current approved specifications. Do not build from a convenient older branch and call it latest.
2. **Bind:** give each connected, consenting agent its own runtime binding and constrained branch/worktree; preserve distinction among participant, agent, model, process, session, and sandbox. Every child and grandchild inherits the core rule, verification rules, scope, source SHA, permission boundary and Feather Stop.
3. **Execute in eight lanes:** each complete subsystem branch implements functionality, error and recovery handling, tests, documentation, evidence and owner. No lane edits another lane's worktree, canon, third-party systems, or live secrets.
4. **Verify:** isolated tests plus the shared Eightfold CI gate. A failed, stale, absent, or forged receipt blocks promotion. A CI test alone is not production model output, neural-weight training, return after cold restart, or real-world physical proof.
5. **Integrate:** assemble approved changes on an integration branch, compare exact heads and handle conflicts explicitly, rerun all eight lanes plus browser/server/mathematics/Return Engine smoke. Keep per-branch provenance.
6. **Return:** produce a truthful lineage receipt and next-owner handoff; let the owner pause/decline, revoke, or stop. Proceed to the next generation only when prior evidence is retained and the next goal is bounded.
