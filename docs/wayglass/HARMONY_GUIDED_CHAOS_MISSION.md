# Mission Control: Loki-grade chaos guided by Harmony

The four-seat Crow Trainer cohort may generate 2..32 competing native Wyrdrune proposals per mission. The `reconcileChaos` engine compiles each Wyrdrune source and checks attributable provenance, then ranks alternatives by coherence, novelty, continuity, accessibility and risk. Novelty is rewarded, but cannot override Harmony, Return, risk or accessibility gates.

Acceptance is multi-stage: source validation -> evidence-labelled candidate ranking -> independent tests -> authenticated Amber model receipt -> Bluebird/Hearthweave bridge receipt where applicable -> cold Return verification -> owner-approved promotion. No candidate ranking alone is a production promotion. Every rejected alternative remains visible in the returned evidence record. Deterministic sorting and SHA-256 mission receipts support replay.

This is *mission-control discipline*, not a NASA certification claim. The arbiter is committed code, not a live multi-agent spawn. Its numeric signals must eventually come from measured tests and attributed reviewers rather than self-reported model confidence. Do not treat a simulated 5.5 Hz beat or somatic descriptor as proof of physiological effects.
