## Module contract and design

`mountWayglassSoundComposition(root,{composition,soundscape,storage})` mounts a complete desk. Default composition is the shared somatic bus composition. ArcSweep child must inject its inherited StorySoundscape composition and soundscape delegates. Singleton construction does not enable sound. Host registration is performed by the integration owner.

- Separate explicit evolving-score and sound-enable controls; density [0,1], evolution interval [1,30] seconds, mono projection.
- Eight bounded sound objects use the engine signed coordinates [-1,1]. Pointer/touch dragging and keyboard arrows preserve actual source/region metadata. Shift gives fine keyboard movement. Gain and mute address the selected layer; existing node identities survive updates.
- Source ledger and live status show actual engine state. Bridge proposal attempts display unavailable failures; a local source label is never presented as proof of remote delivery.
- Shared soundscape Feather/release delegates carry the global latch. Injected engine fallback supports isolated engine tests. Release starts neither generation nor audio.
- Browser save/recover uses engine-owned checkpoint validation. Successful recovery reports paused score and sound off. Missing/private-storage failures remain visible.
- Room teardown unsubscribes and removes handlers; it leaves the user-started shared composition running. The engine/bus and global Feather own lifetime.

No perpetual rendering loop, additional AudioContext or global duplicate composition is created by the UI. Fixed sound-layer count bounds DOM updates. The responsive stage has 48px object targets, native accessible controls, semantic status/errors, text-only source rendering, keyboard positions and no decorative animation.
