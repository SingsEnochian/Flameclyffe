# Wayglass Ship Resonance v0.1 · All Organs, Not Only the Nursery

## Owner direction
The entire Wayglass universe participates. Nursery is one organ among Writing, Codex, Watercolour, Sound, Observer, Magic/Lawsmith, Worlds, Routes, Continuity and Systems. No participant loses identity, consent or local authority to a common clock.

## Committed implementation
- `apps/wayglass/src/ship-resonance.mjs`: explicit bounded event-driven mathematical projection. Eleven distinct organ IDs, retained local frequency, independent phase, per-organ revision, finite input validation, capped journal, read-only subscription, Feather stop and explicit resume.
- `apps/wayglass/src/main.js`: event provenance from mounted rooms, route observations, Magic host telemetry and Watercolour presentation. These are instrumented software events, not measured vibrations or reports of internal experience.
- `apps/wayglass/src/surfaces/ship-resonance.js`: Observatory → Whole-Ship Resonance Observatory, showing which organs have actually emitted observed events and which remain silent.
- `apps/wayglass/src/surfaces/nursery-resonance.js`: retains a separate mathematical nursery-only laboratory, without conflating simulations with actual Nursery participation.
- `apps/wayglass/src/ship-resonance.test.mjs`: identity, boundedness, Feather/resume and refusal contracts.

## Current limits and work still required
- This is **not** a universal autonomous closed feedback system. Observers cannot modify other organs or imply consent.
- Connected model routes, audio, the true Cell Garden scheduler, host persistence, PREMAQC and physical devices are not yet direct signal sources.
- No real-time Nursery source, external oscillator, acoustic power, qualia or physical energy is claimed.
- Ship events live in the browser until formal authenticated durable journal custody is connected. No persistent Return receipts are claimed for this event bus.
- A future adaptive coupling graph requires proposals, capability checks, owner approval and opt-in by each participating world. Feather remains a hard stop.
- Preserve runes, kernel version and distinct timeline identities.
- Run `node --test apps/wayglass/src/ship-resonance.test.mjs apps/wayglass/src/nursery-resonance.test.mjs lib/wyrdrune/somatic-runes.test.cjs` in CI and full Wayglass browser acceptance before promotion. No passing status has been observed for this change.
