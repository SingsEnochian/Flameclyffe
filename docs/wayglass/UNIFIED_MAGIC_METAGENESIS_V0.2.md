# WTL Lawsmith and Metagenesis v0.2

Owner-approved development candidate, attached to the Unified Magic integration. No live production promotion or claim of physical law discovery.

## Author law structure

The bounded declarative law language supports named state properties, constants, relative L/T/M dimension vectors, derivatives, arithmetic, and dimension-checked `sin`, `cos`, `abs`, `min`, `max`. A state requires a derivative with its declared dimension divided by time. Expressions are parsed and interpreted, never evaluated as host code. Each compiled law has a content-derived identity, parent identity and generation. A candidate can add or remove properties. Compatible states twine derivatives and report per-property divergence; incompatible states execute independently and preserve a correspondence question, without inventing a numeric comparison of unlike dimensions.

Example:

```text
law "Harmonic"
state x [1,0,0] = 0.9
state v [1,-1,0] = 0
const k [0,-2,0] = 1.96
derivative x = v
derivative v = -k * x
```

In the Lawsmith room, edit both laws, change the candidate's structure, weave, inspect the native WTL Return and preserve its lineage. Numerical outcomes are real computations; they are not Waking World measurements.

## Upgrade the native WTL kernel

The portable canonical kernel exports a versioned upgrade factory. It compiles candidate native pure `operator` declarations with the existing parser, executes core and candidate regression tests, retains version lineage, supports explicit breaking-change adoption, pinned execution and rollback. The House kernel custody persists the active registry and verifies its integrity and test results at restoration. New Magic executions use the active kernel, and the version identity is sealed in the Return and journal. Other existing WTL consumers retain their original base behaviour until explicitly connected to the versioned registry; no silent global semantic change.

Example extension: `operator fold(x) = x * 2;` with a native WTL test returning `fold(3)` and expected output `[6]`. In the Lawsmith room, propose, verify, adopt or reject, select retained versions, execute and return to an earlier version. No downloaded code, host commands, external bridges or automatic adoption. Syntax, IR/backend changes outside the pure operator layer remain future source-level upgrade proposals requiring conformance and migration review.
