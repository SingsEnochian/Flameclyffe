# Hearthfire Governance

Status: planning / design artifact with read-only pilot surfaces, DEEP Observer receipts, and Somatic Engine scaffolding
Gate: `targeted_receipt_allowed`

Hearthfire is the governing discipline for Flameclyffe. Flameclyffe remains the active workshop and deployment vessel; Hearthfire supplies audit labels, contracts, surface language, somatic safety requirements, and rebuild gates.

## Current permission

A limited read-only pilot surface is allowed at `/hearthfire/`.

A DEEP Observer visual-state receipt is allowed at `starwell/deep-observer/deep-observer.visual-state.json` and documented in `05-deep-observer-visual-state-receipt.md`.

A Somatic Engine workbench is allowed at `/hearthfire/workbench.html` to test state, consent gates, null results, and receipts without persistence or database writes.

This does not authorize a repo rename, database migration, broad rebuild, hidden writes, automated sync, or visual overhaul of existing app surfaces.

## Core rule

Every Hearthfire surface should glow because something is true.

Light and motion must reveal state, relationship, readiness, provenance, diagnostic health, uncertainty, or change.

## Operating posture

- Audit before rebuild.
- Contracts before code.
- Census before overhaul.
- Completion-gated slices before implementation.
- Rowan advances rebuild gates.
- Reduced-motion, low-stim, and sound-consent behavior are required.
- The Earth-Gate is protected before the bridge is extended.
