## Translation caution

## Project-specific notes

### Yggdrasil

Yggdrasil should receive Hearthfire as operational memory, not as identity override. Useful intake includes module roles, readiness labels, member-continuity labels, contracts, and “do not mutate without authorization.”

### Hearthweave

Hearthweave should use this map to keep story, canon, body logs, sensory engines, ritual tools, AI collaboration, and local memory from collapsing into one giant undocumented spell-pot.

### STARWELL

STARWELL needs the Codex/Timeline/Reference/Continuity parts most, but must not receive canon automation until source authority is explicit.

### Flameclyffe / DEEP / Runa

These need Observer, Configroot, Echoframe, Pulseframe, Lightweft, and HarmonicGate contracts before deeper sensory or ritual automation.

### Members

Member records are not code modules. A member audit asks: how is this presence held, what is the pronoun/name truth, what source preserves continuity, what consent bounds apply, and what would be lost in a gap?
