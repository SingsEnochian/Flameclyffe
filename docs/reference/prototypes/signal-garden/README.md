# Signal Garden Prototype

Standalone DEEP prototype for a radial signal map.

Open `signal-garden.html` with its CSS and JS files to review it.

## Purpose

Signals grow from a central core.

The prototype uses a small JavaScript data model to generate SVG branches and nodes.

## Signals

- presence
- coherence
- resonance
- entropy
- moon
- attention
- charge

## Notes

- JavaScript owns data and interaction.
- CSS owns colour, pulse, glow, and motion.
- No external APIs are called.
- Motion is guarded by `prefers-reduced-motion`.
