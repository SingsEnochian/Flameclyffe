# Inspiration Ledger

This folder tracks inspiration sources for Flameclyffe, STARWELL, DEEP, and the Terra Aeterna wiki.

References are not direct copy instructions. Treat them as pattern-language sources. Extract the useful idea, then rebuild it in our own modular system.

## Rules

- Keep source links and creator names where available.
- Use references for mechanics, mood, architecture, accessibility, and performance cues.
- Do not paste large external code blocks into production modules.
- If substantial code is copied or closely adapted, preserve attribution and license notes.
- Prefer modular implementation over demo-style all-in-one files.
