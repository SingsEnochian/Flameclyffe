# CSS Over JS Modularity

Source: https://codepen.io/web-strategist/pen/wBzLaGY

Use for the modular rule that state and expression stay separate.

Targets:

- style contract
- theme tokens
- cascade layers
- typed variables
- component attributes

Rule:

JavaScript decides state. CSS expresses state. SVG draws links. Three/WebGL handles heavy geometry.

Notes:

- Good reference for keeping modules clean.
- Useful for both wiki and instrument styling.
- Keep experimental features optional.
