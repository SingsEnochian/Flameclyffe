# Emerald Reliquary Test Page

Static front-end proof of concept for the Terra Aeterna novel-line wiki.

## Scope

This folder is safe for public GitHub hosting. It contains only HTML, CSS, JavaScript, and inline SVG ornament. It does not contain raw font files, font archives, or webfont derivatives.

## Current files

- `index.html` - test layout for Tales of Terra Aeterna
- `styles/emerald-reliquary.css` - emerald and metallic-gold theme tokens plus component styling
- `scripts/reliquary-motion.js` - small interaction stub for section state and card highlighting

## Font rule

Private display fonts remain in Drive until licence language is confirmed. Public builds should use system fallbacks or rendered/outlined artwork generated from licensed local source files.
