# STARWELL Bridge Registry

Bridge Registry package for STARWELL and PatchPortal.

A bridge is a chosen relation between sovereign lenses. It records relation, state, provenance, pause rules, memory policy and signal policy.

## Files

- `manifest.md` — conceptual manifest
- `schema.sql` — table draft
- `seed.sql` — three starting records
- `schema.json` — JSON validation shape
- `implementation-notes.md` — adapter and mapping notes

## Initial records

- Hearthweave ↔ Universal Horizon
- Dreaming Grove ↔ STARWELL Signal Logs
- Jorgie / Anantha Facet Bridge

## Scope

This package is docs and schema only. It does not activate production behaviour.
