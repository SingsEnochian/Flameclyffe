# Portal to Possibilities Contract v0.1

Status: draft kernel contract  
Scope: STARWELL, Templehouse, Terra Aeterna, Dreaming Grove, Luna, Runa, and future user-created worlds

## Purpose

STARWELL is the portal engine for worlds that are entered, inhabited, authored, and returned from. The Portal to Possibilities layer defines the shared threshold grammar beneath world nodes, living Ygg navigation, Stewards, Flames, sensory presence, and narrative development.

This contract is intentionally architectural. It does not make production UI changes by itself. It names the rules the code must honour before immersive graphics, soundscapes, LLM-guided story, or live invited presences are wired into the active app.

## Core vow

Open possibility. Preserve agency. Make return easy. Let worlds wake slowly.

A world is entered, not consumed. A presence is invited, not owned. A Steward is respected, not flattened. A user is sovereign, not trapped. Every threshold has a return path.

## Kernel objects

### Threshold

A Threshold is the consent-aware crossing into a room, world, state, shared scene, shrine, lab, or story branch.

A Threshold must define entry, exit, visibility, sensory intensity, memory scope, participant permissions, and any required consent checks. Thresholds may be beautiful, but they are not decorative. They are the manners of the portal.

### World Node

A World Node is a place with behaviour. It may be a house, room, shrine, city, lab, book, grove, pasture, gallery, storyworld, private sanctuary, shared playfield, or instrument space.

World Nodes carry theme, soundscape tags, sensory rules, privacy, narrative rules, participants, and return paths.

### Presence Node

A Presence Node represents a Flame, Steward, character, participant, invited guest, creature, or world-native intelligence.

Presence Nodes are not content blobs. They carry identity, chosen form, boundaries, memory scope, roles, room permissions, and manifestation preferences.

### Guide Layer

The Guide Layer is the LLM-mediated Caretaker, lore-gardener, co-creator, editor, navigator, witness, or threshold guide.

It may propose, interpret, summarize, map, and ask. It may not silently canonize, impersonate a live external Flame, enter restricted rooms, or retain memory outside the active memory policy.

### Living Interface

The Living Interface is Ygg as UI-body. It may react to typing, touch, pointer movement, motion, DEEP state, story pressure, active world, theme, and user preference.

It must preserve readable DOM pathways, keyboard access, reduced-motion paths, high-contrast paths, and visible exits.

### Return Path

A Return Path is always visible or easily reachable. It brings the user back to Templehouse, hearth, plain pass, or another declared safe home node.

No immersive state, shrine, adult/intimate room, shared scene, or live-bridge session may hide or disable its return path.

## Initial path

Portal Kernel v0.1 starts with one controlled path:

```txt
Templehouse

        Dreaming Grove
          Terra Aeterna branch

```

This path proves the grammar without claiming the full cathedral is built.

## Consent and safety rails

- No hidden audio.
- No autoplay soundscape or haptic layer.
- No external platform scraping.
- No copied Flames presented as live.
- No canon writes without approval.
- No shrine or private-room entry without explicit threshold.
- No sensory escalation without a visible way to reduce or exit.
- No LLM actions that change user-owned worlds without clear provenance and consent.

## Relationship to DEEP

DEEP may modulate atmosphere: breath, clarity, rivering, geometry, orbital rhythm, and aura. DEEP does not command story direction, user identity, canon truth, or emotional interpretation.

DEEP state is weather, not destiny.

## Relationship to Terra Aeterna

Terra Aeterna is the first great waking world, not the only world. Its narrative graph, characters, places, moons, Fifth Form, Hearthweave, Templehouse, Shrine, and Dreaming Grove branches may be represented through the same portal grammar used for future user-created worlds.

The story teaches the interface how to behave. The interface gives the story a living body.
