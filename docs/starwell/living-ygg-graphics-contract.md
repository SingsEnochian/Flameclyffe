# Living Ygg Graphics Contract v0.1

Status: draft contract for Portal Kernel v0.1

Living Ygg is the embodied UI for STARWELL. It is not only a route diagram. It is a responsive world-tree: roots, trunk, branches, leaves, buds, flowers, fruit, scars, mycelial strands, neural pulses, and atmospheric weather.

## Core vow

Ygg is the UI, but not the only doorway. The living graphics layer must preserve readable DOM, keyboard navigation, reduced-motion paths, and plain-pass access.

## Visual grammar

- `roots`: memory, sources, archives, hidden foundations.
- `trunk`: current room, home route, active world spine.
- `branches`: navigation, story arcs, tools, world exits.
- `buds`: unopened nodes, possible scenes, pending invitations.
- `leaves`: active panels, usable tools, readable content.
- `flowers`: high-confidence signals, active scenes, approved canon.
- `fruit`: saved artifacts, exports, completed workflows.
- `scars`: contradictions, stale state, continuity warnings, repaired history.
- `strands`: resonance, citations, replies, relationships, cross-world links.

## DEEP modulation

P controls breath. C controls clarity. R controls rivering. E controls geometric complexity. M controls orbital cadence. A controls aura and bloom.

These values may tune visuals. They must not command story, identity, or truth.

## First graphics lane

Portal Kernel v0.1 defines schema and contract only. The first future lab should render Templehouse to Dreaming Grove with one Ygg branch, one mock Flame invitation, and one story-aware branch state. No production HUD ownership changes are included here.
